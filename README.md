# DeshX — Fast Indian News Fast, bite-sized Indian news aggregator delivering 60-word summaries across top stories, national, world, business, sports, entertainment, and technology, in English and Hindi. ## Tech Stack - **Frontend:** React + Vite + TypeScript, Tailwind CSS - **Backend:** Node.js + Express, serving a REST API and live news ingestion ## Run Locally **Prerequisites:** Node.js 1. Install dependencies: `npm install` 2. Run the app: `npm run dev` ## Deployment - **Frontend:** Deployed via Firebase Hosting (`firebase deploy --only hosting`) - **Backend:** Deployed via Render (see `render.yaml`) Set `VITE_API_URL` in a `.env.production` file to your deployed backend's URL before building the frontend for production.
